# Crestmark Premium

Build a State-of-the-Art E-Commerce Website for Crestmark Enterprises

Create a premium, modern, elegant and highly responsive e-commerce website for Crestmark Enterprises, a Zimbabwean manufacturer of high-quality soy-based food products.

The website should feel like a premium African food brand, combining sophisticated editorial design, modern e-commerce UX, natural food aesthetics and a strong sense of trust.

Do NOT make it look like a generic corporate template.

1. BRAND

Company: Crestmark Enterprises

Tagline:
Quality Soy. Trusted Nutrition.

Business:
Crestmark Enterprises manufactures high-quality soy-based food products for households, retailers, restaurants, institutions and commercial customers across Zimbabwe.

Products currently include:

Tofu
Instant Soy Porridge
Vital Gluten
Soy Seasoning

Brand values:

Quality
Integrity
Innovation
Community
Sustainability

The website should communicate:

Premium quality + nutrition + local Zimbabwean production + reliability + modernity.

2. DESIGN DIRECTION

Create an exceptionally polished visual identity.

Overall aesthetic

Think:

Luxury food brand
Premium African FMCG company
Modern organic food company
Editorial magazine design
Sophisticated e-commerce experience

Avoid:

Generic Bootstrap-looking layouts
Excessive rounded cards
Overuse of gradients
Cheap-looking icons
Excessive animations
Clutter
Stock-photo-heavy corporate layouts

The website should have lots of breathing room, excellent typography and carefully controlled visual hierarchy.

3. COLOUR PALETTE

Use a sophisticated natural palette:

Deep forest green: #16382B
Dark green: #10271E
Warm cream: #F5F0E5
Off-white: #FCFBF7
Muted gold: #B89452
Charcoal: #202823
Soft sage: #AEBBAF

Use gold sparingly for premium accents.

The overall appearance should feel earthy, luxurious and contemporary.

4. TYPOGRAPHY

Use an elegant serif font for major headings.

Recommended:

Playfair Display or Cormorant Garamond

Use a modern sans-serif for body text and navigation.

Recommended:

DM Sans, Inter, or Manrope

Large editorial headings should be used throughout the website.

Example:

QUALITY SOY.
TRUSTED NUTRITION.

Typography should be one of the major visual features of the site.

5. HERO SECTION

Create a cinematic full-screen hero.

Use beautiful high-quality imagery showing:

Soybeans
Natural ingredients
Premium food
Tofu
Soy products
African food production

Hero content:

CRESTMARK ENTERPRISES

Quality Soy.
Trusted Nutrition.

Supporting text:

High-quality soy-based products, proudly manufactured in Zimbabwe for households, retailers and institutions.

Primary CTA:

SHOP OUR PRODUCTS

Secondary CTA:

DISCOVER CRESTMARK

Include subtle scroll animation.

The hero should immediately communicate that this is a premium food brand.

6. NAVIGATION

Create a clean sticky navigation bar.

Desktop:

CRESTMARK | About | Products | Our Story | Contact | 🛒 Cart

The navigation should become transparent over the hero and transition into a solid/blurred background when scrolling.

Mobile:

Use a sophisticated hamburger menu.

The navigation must remain extremely clean.

7. SHOPPING SYSTEM

Build a complete shopping cart system.

IMPORTANT:

THERE MUST BE NO LOGIN OR REGISTRATION.

Do not create:

User accounts
Sign-in
Sign-up
Passwords
Customer dashboards

Customers should be able to shop immediately as guests.

8. PRODUCT SHOP

Create a dedicated Shop section/page.

Products:

TOFU

Protein-rich soy product and nutritious meat alternative.

INSTANT SOY PORRIDGE

Convenient ready-to-mix porridge containing plant-based protein and essential nutrients.

VITAL GLUTEN

High-protein wheat derivative used as a functional ingredient in bakery and food manufacturing.

SOY SEASONING

Soy-based seasoning designed to enhance everyday meals.

Each product should have:

Beautiful product image
Product name
Short description
Price
Pack size
Quantity selector
Add to Cart button
Quick View
View Product button

Use elegant product cards with subtle hover effects.

9. PRODUCT DETAIL PAGE

Clicking a product should open a beautiful product detail page.

Include:

Large product photography.

Product name.

Price.

Available pack sizes.

Quantity selector.

Large:

ADD TO CART

button.

Also include:

Product description
Ingredients where provided
Nutritional information where provided
Usage suggestions where appropriate
Related products

Do not invent nutritional facts or ingredients that Crestmark has not supplied.

10. SHOPPING CART

Create a beautiful slide-out shopping cart.

When the customer clicks the cart icon, open a right-side drawer.

Display:

Product image
Product name
Pack size
Quantity
Unit price
Subtotal
Remove button
Increase/decrease quantity

At the bottom:

ORDER TOTAL

Then a large button:

ORDER VIA WHATSAPP

The cart should update instantly.

Show the number of items in a small badge on the cart icon.

Persist the cart using localStorage so refreshing the page doesn't empty it.

11. WHATSAPP ORDER SYSTEM

This is extremely important.

There should be NO traditional checkout/payment page.

Instead, when the customer clicks:

ORDER VIA WHATSAPP

the website should automatically generate a WhatsApp message containing the complete order.

Use this WhatsApp number:

+263 786 362 216

Use the WhatsApp click-to-chat mechanism.

Generate a message similar to:

Hello Crestmark Enterprises 👋

I would like to place an order:

Order
• Tofu × 2
• Instant Soy Porridge × 3
• Soy Seasoning × 1

Total: USD 35.00

Customer details
Name: ______
Phone: ______
Delivery location: ______

Please confirm availability and delivery arrangements.

Thank you.

The message should be generated dynamically from the customer's cart.

12. CUSTOMER INFORMATION

Before sending the WhatsApp order, show a simple guest checkout form.

DO NOT require an account.

Fields:

Full Name
WhatsApp Number
Delivery Location
Optional Order Notes

Then:

SEND ORDER TO WHATSAPP

Validate the fields before opening WhatsApp.

18. TECHNICAL REQUIREMENTS

Build the website using modern, maintainable code.

Preferred stack:

Next.js + TypeScript + Tailwind CSS

or, if the environment does not support Next.js:

HTML + CSS + JavaScript

The shopping cart must work entirely on the frontend.

Use localStorage for cart persistence.

No database is required initially.

No authentication system.

No customer accounts.

No complicated backend.

WhatsApp is the order channel.

19. WHATSAPP ORDER FLOW

The complete flow should be:

Browse products

↓

Select product

↓

Choose pack size

↓

Choose quantity

↓

Add to Cart

↓

Open Cart

↓

Review Order

↓

Enter Name + Phone + Delivery Location

↓

Click "ORDER VIA WHATSAPP"

↓

Generate WhatsApp message automatically

↓

Open WhatsApp

↓

Customer sends order

↓

Crestmark receives the order directly on WhatsApp

Make this experience extremely smooth.

20. IMPORTANT BUSINESS LOGIC

Do not pretend an order has been paid for.

WhatsApp should be used to:

Receive the order
Confirm product availability
Confirm pricing
Confirm delivery
Arrange payment

If product prices are not available, allow the admin to easily update them later.

The website should never invent product prices, nutritional information, ingredients or certifications.

21. ADMIN-FRIENDLY PRODUCT DATA

Keep products in a simple data structure so Crestmark can later update:

Product name
Description
Price
Images
Pack sizes
Availability
Category

without rebuilding the website.

22. FINAL DESIGN STANDARD

The finished website should look like it was designed by a top-tier international digital agency.

It should feel:

Premium.
Elegant.
Modern.
Minimal.
African.
Trustworthy.
Commercial.
Responsive.

Do not make the design look like an AI-generated template.

Prioritise:

Typography + photography + whitespace + layout + micro-interactions + excellent mobile UX.

The final result should be good enough for Crestmark Enterprises to use as its official public-facing website.
